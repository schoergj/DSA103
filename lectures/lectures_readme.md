# General information on the lectures

In this folder, you will find sub-folders for each session, which contains the lecture slides, materials (data sets, code snippets, notebooks) and a `userfolder`. 

In order to avoid merge conflicts when synchronising your fork, please only use the `userfolder` for your own solutions and notebooks when following along the lecture. To this end, you can use the templates provided in the folder or copy the corresponding files and data sets from the ``material`` folder into the `userfolder` and modify them there. **Please do not modify scripts or notebooks within the ``material`` folder directly, this will lead to merge conflicts in the git process!**
