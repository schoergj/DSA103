# General information on assignments

To fortify and deepen the lecture content, throughout the course, you will receive several assignments, uploaded after their announcement in the lecture to the ``assignments folder`` in this repo. Their completion is optional, however, will contribute as bonus to the final grade (maximum improvement of half a grade). We highly recommend you to use this opportunity and to challenge yourself with these exercises.

In order to complete an assignment, all tasks in the assignment description/notebook need to be carried out. The assignment will be counted as complete if all relevant steps in the task are carried out and the questions in the end are answered. Code needs to be executable without errors using the DSA 103 environment.

The assignments are to be submitted to dimitrios.xynos@chem.uzh.ch. Generally, this needs to be done before the following week's Friday session starts (i.e. 08:00), when the solution of the assignments will be discussed. Afterwards, the solutions will be uploaded into this folder. If the deadline should change, we will notify you accordingly.

After submitting your solutions, you will receive feedback if the assignment was found to be complete. Optionally, more personalised feedback points may be included. Our TA Dimitrios is happy to join our Q&A sessions for more detailed, specific discussions on assignments and your solutions - simply let us know before the next Q&A session if you wish for this.
